The repo is split into two independent layers wired by HTTP: the `backend/` Spring Boot service exposes REST endpoints (`/reference-points`, `/kiosks`, `/orders`) over MongoDB Atlas, and the `frontend/` Flutter app calls them via `API_BASE_URL`. Cross-cutting contracts are defined in the README's API surface and in shared data shapes (GeoJSON `[longitude, latitude]` coordinates, `Order.pinCliente`). The frontend targets Android/iOS emulators through `10.0.2.2:8080` to reach the host backend, and both sides depend on external free-tier services (MongoDB Atlas M0, Google Maps API key) configured at runtime rather than checked in.
